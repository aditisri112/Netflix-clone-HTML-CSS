# Netflix Clone (HTML & CSS)

A front-end clone of the Netflix landing page, built with plain HTML and CSS — no frameworks, no JavaScript.

## 🔗 Live Demo
https://aditisri112.github.io/Netflix-clone-HTML-CSS/

## ✨ Features
- Full-screen hero section with background image and dark gradient overlay
- Responsive navigation bar with logo, language selector, and sign-in button
- Email sign-up call-to-action
- Trending Now horizontal poster scroll
- FAQ accordion (built with native HTML `<details>`/`<summary>` — no JS)
- Fully responsive layout for desktop, tablet, and mobile

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, custom properties, gradients)
- Google Fonts — Poppins & Martel Sans

## 📁 Project Structure
```
Netflix-clone-HTML-CSS/
├── assets/         # images, icons, logo
├── favicon         # site favicon
├── index.html      # main page markup
├── style.css       # all styling
└── README.md
```

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/aditisri112/Netflix-clone-HTML-CSS.git
   ```
2. Open the project folder
   ```bash
   cd Netflix-clone-HTML-CSS
   ```
3. Open `index.html` in your browser — no build step or dependencies required.
